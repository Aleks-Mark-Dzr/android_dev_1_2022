#m16_new_permissions

Учебное Android-приложение с картой OpenStreetMap для создания и хранения собственных
меток достопримечательностей. Пользователь может поставить метку по текущей геопозиции
или выбрать произвольную точку на карте, добавить описание и фотографии, а затем
перенести свои данные на другое устройство через резервную копию.

## Возможности

- просмотр карты OpenStreetMap, масштабирование и переход к текущему местоположению;
- отображение предустановленных достопримечательностей;
- создание метки по текущей геопозиции, обычным нажатием в режиме выбора точки или
  долгим нажатием по карте;
- редактирование названия, описания, координат и фотографий пользовательской метки;
- перемещение пользовательской метки перетаскиванием и её удаление;
- поиск по названию и описанию с выпадающими подсказками;
- добавление нескольких фотографий из камеры или галереи, полноэкранный просмотр и
  удаление отдельных снимков;
- отправка метки и её фотографий в другое приложение;
- экспорт пользовательских меток вместе с фотографиями в ZIP-архив и восстановление
  из него без удаления более свежих локальных данных;
- сохранение пользовательских меток и фотографий между запусками приложения.

## Разрешения

Приложение запрашивает разрешения только перед функцией, которой они нужны:

| Разрешение | Для чего используется |
| --- | --- |
| `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` | Показ текущего положения и создание метки по геопозиции. Без разрешения карту и метки в произвольных точках всё равно можно использовать. |
| `CAMERA` | Съёмка фотографии для метки. Разрешение не требуется при выборе изображения из галереи. |
| `INTERNET` | Загрузка тайлов OpenStreetMap. |
| `WRITE_EXTERNAL_STORAGE` (только до Android 12L) | Совместимость со старыми версиями Android. Экспорт и импорт резервных копий выполняются через системный Storage Access Framework. |

Камера объявлена необязательной аппаратной возможностью, поэтому приложение можно
установить и на устройство без камеры.

## Технологии и устройство проекта

- **Kotlin**, Android SDK 24–34;
- **Android Views**, View Binding, Fragment и AppCompat;
- **ViewModel**, Kotlin Coroutines, `StateFlow` и `SharedFlow`;
- **osmdroid** для карты OpenStreetMap;
- **Gson** для сериализации меток;
- `SharedPreferences` для описаний меток и внутреннее хранилище приложения для фото;
- `FileProvider` для безопасной передачи фотографий камере и другим приложениям;
- Storage Access Framework для выбора файла резервной копии.

Основные компоненты:

```text
app/src/main/java/com/example/m16_new_permissions/
├── data/
│   ├── backup/       # ZIP-экспорт и восстановление
│   ├── local/        # SharedPreferences и файловое хранилище фотографий
│   ├── repository/   # объединение встроенных и пользовательских меток
│   └── service/      # получение последней известной геопозиции
├── domain/           # модели и интерфейсы
├── presentation/     # ViewModel и фабрики
└── ui/map/           # экран карты, диалоги и поисковые подсказки
```

Резервная копия имеет следующий формат:

```text
attractions.json          # версия формата и список меток
photos/photo_<uuid>.jpg   # приложенные фотографии
```

При импорте метки объединяются по идентификатору. Если метка уже существует, остаётся
версия с более поздним `updatedAt`; встроенные метки в архив не включаются.

## Требования

- Android Studio с Android SDK 34;
- JDK 17;
- устройство или эмулятор с Android 7.0 (API 24) либо новее;
- доступ в интернет для первоначальной загрузки Gradle-зависимостей и тайлов карты.

## Запуск

1. Откройте каталог `m16_new_permissions` как отдельный проект в Android Studio.
2. Дождитесь завершения Gradle Sync.
3. Выберите устройство или эмулятор с API 24+.
4. Запустите конфигурацию `app`.

Сборка из командной строки:

```bash
cd m16_new_permissions
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

> В Linux исполняемый бит wrapper-файла может отсутствовать. В таком случае используйте
> `bash ./gradlew assembleDebug` или один раз выполните `chmod +x gradlew`.

## Как пользоваться

### Геопозиция и новые метки

1. Нажмите **My Location**, чтобы выдать доступ к геопозиции и перейти к текущей точке.
2. Нажмите **Добавить метку**, чтобы создать запись в текущем местоположении.
3. Для другой точки нажмите **Метка на карте**, затем коснитесь нужного места. Долгое
   нажатие по карте также открывает создание метки.
4. Заполните название и описание, при необходимости скорректируйте координаты и добавьте
   фотографии из камеры или галереи.

Нажатие на пользовательскую метку открывает её редактирование. Метку также можно
перетащить долгим нажатием. Предустановленные достопримечательности доступны только для
просмотра.

### Резервная копия

1. Нажмите **Копия меток**.
2. Выберите **Сохранить копию** и укажите файл через системный диалог. Поддерживаются в
   том числе провайдеры облачных хранилищ, доступные на устройстве.
3. Для восстановления выберите **Восстановить из копии** и откройте созданный ZIP-файл.

Резервная копия содержит только пользовательские метки. Не изменяйте структуру архива
вручную: некорректный или созданный более новой версией приложения формат будет отклонён.

## Проверка проекта

Локальные unit-тесты проверяют совместимость текущей модели фотографий со старыми
сохранёнными записями. Полный набор проверок:

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Инструментальные тесты требуют подключённого устройства или запущенного эмулятора:

```bash
./gradlew connectedDebugAndroidTest
```

## Ограничения

- карта без сети показывает только тайлы, уже находящиеся в кэше;
- текущее положение берётся из последней доступной системной геопозиции и может быть
  недоступно сразу после запуска или устареть;
- данные меток хранятся локально и не синхронизируются автоматически — для переноса
  используйте ZIP-архив;
- отказ в разрешении камеры или геопозиции отключает только соответствующую функцию;
- экспортировать нечего, пока пользователь не создал хотя бы одну собственную метку.
